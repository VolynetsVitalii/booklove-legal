# Файл лежит в подпапке project-репозитория GitHub Pages, а роботы читают
# robots.txt СТРОГО из корня домена (volynetsvitalii.github.io/robots.txt).
# То есть прямо сейчас этот файл роботами не читается - он лежит здесь,
# чтобы поехать вместе с сайтом на собственный домен и заработать в ту же
# минуту. Никакого вреда от его присутствия нет, а забыть его при переезде
# было бы легко.
#
# Индексацию страниц при этом определяют мета-теги robots на самих страницах,
# и они работают уже сейчас: на 404.html стоит noindex, на остальных ничего
# не стоит, то есть индексация разрешена.
